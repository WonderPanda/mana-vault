# React Native (Expo)

- Expo Router for file-based routing in `apps/native/app/`
- HeroUI Native for UI components
- Uniwind for Tailwind-like styling
- Use `@/` alias for src-relative imports
- Key deps: Expo 54, React Native 0.81
